# Roadmap

## v1.0 Scope (Current)

- ✅ NIS2 Article 21 mapping
- ✅ GDPR Article 32 mapping
- ✅ AWS Terraform support
- ✅ Three report formats (dev, security, auditor)

## Future Work

### Multi-cloud Support

- Azure (NIS2/GDPR mapping for Azure Resource Manager)
- GCP (NIS2/GDPR mapping for GCP resources)

### Additional Frameworks

- ISO 27001 (already covered by CIS benchmarks to some extent)
- NIST CSF (US-focused, but international adoption exists)
